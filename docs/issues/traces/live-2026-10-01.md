## Defects found (not fixed)

1. **`drive --out` with a relative path is written relative to the service's working directory, not the caller's.** `--out travel.jsonl` from `$ROOT` produced `travel.jsonl` in the directory the service was started from (it was moved into the evidence dir). The help's own example uses a relative path; `shot` refuses relative paths (`reading.ml` "screenshot path must be absolute") but drive's `out` passes through unresolved. Under `leash.service` the file would land in the unit's cwd.
2. **Trace steps lose the operation distribution.** Every trace step has `"operations": []` although the reply's step carries `probabilities.op` (e.g. CLICK 0.98, BLOCKED 0.02). `Traces.safe_step` (`traces.ml` ~l.387) keeps only keys accepted by `P.Operation.of_string`; JEV's keys are upper case (`CLICK`, `SCROLL_DOWN`, `DONE`) and the wire operations lower case, so all are filtered. trace-qe8c's "JEV's probabilities over every option" holds for targets only.
3. **`final.title` is the URL without scheme**, in the reply's `final` snapshot and therefore in the trace: `quotes.toscrape.com/author/Albert-Einstein/` and `books.toscrape.com/catalogue/category/books/travel_2/index.html`, while the step's `after.title` and `snap` report "Quotes to Scrape" / "Travel | Books to Scrape - Sandbox".
4. **The reply's `operator_state.page.url` is the inferred kind, not the URL** (`"url": "author-<slug>"`, `drive.ml` ~l.136 `shown.url`). The kind-ir9l substitution is meant for JEV's state; it leaks into the reply's operator-state record an agent reads (the nested `page.snapshot.url` still has the real URL).
5. **`about:blank` is a page kind.** Both `page_kind_path`s start with `blank` and `inferred_pages` offers `{name: blank, url_pattern: about:blank}` to the compiler as a draft page of the site.
6. Observation: trace procedures are numbered by completion: the `use: collect-page` child is `n: 1` and its parent `open-category` `n: 2`, with no parent link in the trace entry; the child's choice is `{probabilities: {}, confidence: 1.0}`.
