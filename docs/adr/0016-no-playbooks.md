# No playbooks

Decision of the operator, 2026-10-06, on the corpus of 2026-10-06 (95 paired cells per variant, JEV loop): no playbook 73/95 at $0.0031 and 36 s per cell; notes 74/95 at $0.0035 and 48 s; procedures 69/95 at $0.0035 and 54 s. A one-cell difference is noise; procedures are worse; both cost time. Playbooks — procedures, scripts, notes, page kinds, the loader, the authoring reference — are removed. `drive` is JEV's loop over the page with the text helper and the optional advisor (ADR-0015), nothing else. The best mission form measured is a goal with its result (82%), and that is what the skill says.

Scripts stay as a standalone command, `leash script run TAB FILE`, run on a tab from a file the agent supplies at call time — never installed, never chosen by a model, never part of a playbook.
