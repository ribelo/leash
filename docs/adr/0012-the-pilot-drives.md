# The pilot drives: Luna holds the mission, JEV is the navigator

**Amended by ADR-0014 (2026-10-05):** playbooks are written by hand, not learned; leg memory, the replay and agreement gates, repair, `proposed/`, `[learning]` and inferred page kinds are removed.

The operator's statement of 2026-10-03: "JEV was meant to be the navigator, only and exclusively; all reasoning goes to the model. I want to send Leash and get the result I need, where the result is usually an action — download the invoice, check whether I owe anything — ad hoc, without writing a script first." Three learning rounds and the Flights evidence (five missions reached the prices, none returned an answer) show what was wrong: `drive` was JEV's loop with the planner as a fallback on `BLOCKED`. JEV cannot know a task is done — it can only see that a page looks right — so missions with an answer, a quantifier ("the cheapest", "every"), or an action with a result ("download it") ended `done` with nothing. Measured: JEV finishes navigation tasks 89/92 on Google, exactly as jev-ultrafast's demo does; the demo never asks for an answer, we do.

Decision: **the planner (Luna, max reasoning, the "pilot") owns the mission; JEV (the "navigator") owns the steps.** The pilot reads the mission and the page (bounded text and element table, the agent's own `snap`/`text` view) and issues *legs*: short navigation goals in JEV's language ("open the invoices page", "click the button named Pobierz"). JEV drives each leg with the primitives it is good at. After each leg the pilot looks at the page again and decides: next leg, read the answer, act (download, type a value through the normal action path), hand off, or done — with `result` and `evidence`. The pilot decides what "done" means; JEV never says `DONE` for the mission, only for a leg. Scripts remain JEV's tools inside procedures; a mission without a playbook needs none: the pilot reads the page itself. Playbooks become what they always should have been — a memory of legs that worked on a site, written by the pilot after a mission, so that the next mission on that site spends fewer pilot turns; they are a cache, not a prerequisite.

Cost: a pilot turn is seconds and cents; a navigator step is milliseconds and a fraction of a cent. A typical mission is a handful of pilot turns and tens of navigator steps. That is the price of getting a result instead of a screen, and it is the price the operator asked to pay. Rejected: JEV-first with the planner as a fallback (three rounds of evidence); the trace compiler that reconstructed structure from JEV's footprints (ADR-0011's compile path is withdrawn; its traces, page kinds, gates and repair remain for playbooks the pilot writes); a step list as the unit of learning (navigation is what JEV already does well; what it cannot do is know the result). Ten use cases of the operator's daily life (`docs/use-cases.md`) are the acceptance; passing them is the definition of useful.
