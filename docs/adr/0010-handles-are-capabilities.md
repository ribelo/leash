# Handles are capabilities; there is no owner

Supersedes ADR-0005's owner model. A tab handle is 128 bits from the system's randomness and is the only way to touch that tab: whoever holds it acts; nobody who lacks it can. There is no `owner` string, no `claim`, no `release`, no `not-owner`, and the CLI reads nothing from the harness environment. Agents do not interfere because they do not hold each other's handles, not because they chose different names. Sharing a tab is handing over the handle; the service has no opinion. Losing a handle loses the tab: it closes when idle and a new one is opened. The operator's decision of 2026-10-01: ownership was a lock mislabelled as a name, it made the tool look harness-specific, and an unverified name prevents nothing.

Every tab has an origin, `human` (opened in the Chrome UI or by a page) or `agent` (opened through the protocol), and one rule each: **an agent tab closes after the idle duration; a human tab is never closed by Leash — until an agent takes it, after which it is an agent tab.** The human has no way to hold a handle and no extension will be shipped, so the human hands a tab to an agent by telling it; the agent finds the tab by its URL or title in `list` (which shows no handles) and `take`s it, which mints the handle and flips the origin. The rule is wrong sometimes (a human's Allegro tab closes thirty minutes after the agent finished with it) and predictable always; a tab can be reopened, a tab left open forever cannot be un-left. `handoff`/`resume` stay: they are the agent asking the human to do something on the agent's tab (a login, a CAPTCHA), keyed on the handle, with agent actions refused until resume.

Considered and rejected: peer-credential authentication on the socket (one user account; nothing to separate); a flat pool where any client acts on any tab (the ADR-0005 objection stands: a hundred unattributable tabs); labels as access (labels are for finding, never for acting); human tabs that revert after an agent is done (needs the owner state machine back to know 'done'). Consequences: `list` is for finding, never for acting; `With_human` is the one tab state besides live; expiry is one stage; the authorization matrix is one row; the tool runs from any shell in any harness.
