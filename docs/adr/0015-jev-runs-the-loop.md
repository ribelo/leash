# JEV runs the loop; a bigger model is optional and never owns the mission

ADR-0012 is withdrawn. It was written by the coordinating agent, not decided by the operator, and it inverted his design: it made the planner (Luna) own every mission and reduced JEV to a sub-step. The corpus of 2026-10-05 showed the consequence — JEV was consulted in 12% of cells; the model comparison could not move the results because the model under comparison was barely running.

The operator's design, from the start and restated on 2026-10-05: **`drive` is JEV's loop**, exactly as in jev-ultrafast — one decision-model call per step picks the operation and the target; playbooks give it procedures and scripts to choose from. **The second model has one job: it writes the text JEV cannot write** — the value typed into a field. Nothing else: it does not plan, does not hint, does not judge, does not read answers. When JEV says DONE or BLOCKED the mission ends and `drive` returns the final page (snapshot and text); the agent that called `drive` reads the answer from it. Luna is only the name of the model configured as the text helper; any model may fill it.

What stays from the pilot work: coordinate actions (ADR-0013); `--secret`; the corpus (ADR-0014), which is the instrument that caught the inversion. What goes: the pilot loop, legs, the pilot's own actions, the pilot prompt, `[pilot]` config, `result`/`evidence` (the final page is the result), and every document that says a planner drives, hints, or judges.
