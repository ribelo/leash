# Playbooks are written, not learned; everything is measured on a corpus

**Superseded by ADR-0016 (2026-10-06):** playbooks are removed; nothing is installed per site.

Decision of the operator, 2026-10-05, after the learning rounds of milestones 12–13: automatic map-building is dropped. The pilot writes nothing into playbooks. A playbook is a hand-written artefact by a coordinating agent on the operator's instruction: **mainly scripts** (what JEV and the pilot cannot do by clicking — bulk reading, files, parsing), **procedures** as before (chosen by the decision model at the procedure level, driven leg by leg), and an experimental `notes` field — one free text for the whole playbook, given to the pilot as context — to be measured against procedures rather than assumed worse. The two goals that remain are the operator's own words: relieve the main model of clicking, and let him automate with human-language instructions instead of code. Both are served by `drive` with hand-written playbooks where repeatability matters and none where it does not.

The decision model is a configured choice among JEV and Cloudflare's Clef family (same Decisions API through OpenRouter); its input modalities are read from OpenRouter's model listing, and a multimodal model may be given a screenshot — when the element table has no useful rows, and as an action the model can choose. Nothing about which model, which state, which instruction style, or whether notes or procedures help is decided by argument: a corpus of missions with independent checks, run by one command, produces the table that decides. Removed: leg memory, the replay and agreement gates, procedure repair, `proposed/`, `[learning]`, inferred page kinds. Kept: traces (audit), hand-written playbooks and their loader, scripts as decision-model and pilot actions, the pilot loop, coordinate actions.
