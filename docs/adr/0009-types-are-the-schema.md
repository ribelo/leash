# Types are the schema in Leash too

Leash follows ox ADR-0008: the control protocol's request and reply types and the config record are plain OCaml types with `[@@deriving yojson]`; constrained values (tab cap, durations, owner strings, handles) are small modules with abstract types and smart constructors; secrets are `Redact.t`; environment-dependent checks go through the Door's validator (ox row 14). `docs/protocol.md` remains the wire contract and the types must match it; there is no schema value. CDP messages are the one exception and stay untyped `Ox_json`, because their shape belongs to Chrome.
